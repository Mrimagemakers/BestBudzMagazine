# Optional community server
Install Node 22+ and run npm install, then npm start from the repository root.
Set SITE_ORIGIN to https://mrimagemakers.github.io (an origin has no path), SMTP_URL to a secret SMTP connection URL, MAIL_FROM to your verified sender, PUBLIC_API_URL to the HTTPS origin of this server, and optionally PORT.
Host behind HTTPS with WebSocket upgrade forwarding. Set config.json apiBase to the server HTTPS URL with trailing slash. Never put SMTP credentials in the frontend, config.json, repository, or Pages variables.
Verification links are cryptographically random, expire after 15 minutes, and are consumed once. Email addresses and tokens are in process memory only; restarts invalidate links. Confirmations do not create accounts or authenticate group access. Production accounts require persistent sessions and an auth provider. Email delivery requires a real sender/SMTP service.
Groups are ephemeral, public to anyone who knows the room code, limited to 16 visitors, with payload limits, throttling and heartbeat cleanup. No voice/video, persistent chat, moderation, authenticated membership or authoritative avatar state is provided. Deploy moderation and user identity before a public community launch. Reverse proxies should enforce request timeouts and connection limits. Rate limits use the direct socket address; configure a trusted proxy policy before scaling.
Age self-attestation does not enforce legal age. Pages is a publicly accessible static preview. Use a server-side age/identity provider and protect content delivery if verified age is required.
